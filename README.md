# 📡 IPv4 Subnetting Packet Tracer Lab

## Overview
This project demonstrates subnetting a /24 network into smaller subnets and configuring Cisco devices.

## Subnetting Summary
- Base Network: 192.168.0.0/24
- Subnet Mask: /26 (255.255.255.192)
- Total Subnets: 4
- Hosts per subnet: 62

## Network Design
- LAN-A → 192.168.0.0/26
- LAN-B → 192.168.0.64/26

## Skills Demonstrated
- IPv4 Subnetting
- Cisco Router & Switch Configuration
- Network Troubleshooting
